# Cogmind 简体中文汉化 · 像素字体预览版

适配 **Cogmind Beta 17.1 / build 260906a**，主要测试环境为 Bazzite + Steam Proton。

[下载预览安装包](https://github.com/Drafffffff/Cogmind-ZH/releases) · [安装与回滚](docs/install.zh-CN.md) · [构建说明](docs/build.zh-CN.md) · [第三方来源](THIRD-PARTY.md)

当前版本：`v102-zh-pixel.34-log-scroll-preview`。当前已知清单包含 **56,399 条短文规则、16,757 条段落规则，共 73,156 条**。这些数量包含名称和格式变体，不能换算为全游戏汉化完成率。

## 内容

- Fusion Pixel 12px 简体中文像素字体，中文双格、英文单格，整数倍缩放。
- 名称、教程、部件说明、对白、成就、帮助与手册的中文译表。
- 开场、帮助、手册及部分数据界面的注音到中文显现动画；开场状态文字间距为两格。
- 普通和展开日志的固定段落行布局，避免裁切后重新排版造成中英文混杂。
- 日志观察缓存去重、边框方向校验，以及机器人编号与部件名组合的翻译。

## 预览状态

当前构建通过 18 项宿主回归测试，涵盖译文显现、布局、段落裁切、边框和动态名称。日志段落测试使用真实译表和采样文字，检查五行提示的全部 15 种连续裁切窗口、140 次混合日志重绘以及热重载缓存失效。全表匹配与字体测试另行记录在发布验证清单中。

仍有已知限制：首次出现的动态段落如果只有截断部分可见，需要先观察完整段落才能建立译文缓存；歧义片段保留英文。战斗日志及放大视图的全部滚动场景尚未完成实机验收，终端/黑客动画和地图批量标签也仍需继续验证。pixel.34 的最新缓存去重修正通过宿主测试，完整实机回归尚待完成。

欢迎提交截图和复现步骤：请附游戏版本、字体尺寸、窗口分辨率，以及发生问题的菜单和滚动方向。

## 构建

```sh
python3 tools/setup_build_inputs.py --game-dir /path/to/Cogmind
python3 tools/build_zh.py --animation-layout
python3 tools/test_zh_runtime.py
python3 tools/test_pixel_font.py
```

需要 Python 3、C 编译器、Git、Zig。第三方构建输入由设置脚本从固定来源获取，手册输入从自己的游戏目录复制。详见构建说明。

本仓库发布从本地开发仓库导出的源码快照。维护过程中产生的远端设备清单、个人安装记录、存档和游戏截图保存在本地；部分实机夹具测试需要维护者的本地采样。
